# Планировщик

## Зачем

Система уже умеет считать, что «скоро» и что «просрочено», —
но узнать об этом можно, только открыв админку самому.
Планировщик переворачивает это: система сама регулярно проверяет
все обязательства и готовит напоминания. Это третий шаг очереди;
сама отправка в Telegram — следующий (бот).

## Что именно делаем

Три вещи:

1. **Регулярная проверка.** Раз в 4 часа по фиксированным часам —
   01:00, 05:00, 09:00, 13:00, 17:00, 21:00 (Celery Beat
   из выбранного стека) — планировщик проходит по всем
   обязательствам и счётчикам и решает, о чём пора напомнить.
   Один прогон приходится ровно на конец тихих часов
   по умолчанию — накопившееся за ночь уходит в 09:00.
2. **Журнал уведомлений** — новая «полка» в базе. Каждое
   напоминание — запись: кому, о чём, текст, когда создано,
   когда отправлено. Журнал нужен, чтобы не напоминать дважды
   об одном и том же и чтобы тихие часы могли придержать
   отправку. Виден в админке.
3. **Отправка с тихими часами.** Отправка идёт через «канал» —
   разъём, в который следующая задача воткнёт Telegram. В этой
   задаче реального канала ещё нет, поэтому уведомления копятся
   в журнале со статусом «ожидает» — их видно в админке,
   и это способ проверить работу уже сейчас.

Для запуска руками (без Docker) — служебная команда: один прогон
проверки по требованию.

## Затрагивает

- `core/` — новая модель «Уведомление» + миграция; новый файл
  с логикой планировщика; задача Celery; служебная команда
- админка — журнал уведомлений
- `config/settings.py` — расписание проверки
- `tests/` — тесты планировщика

## Бизнес-правила

**Что порождает напоминание** (правила 7–8, 11 анализа):

1. Обязательство перешло в «скоро» — одно уведомление на цикл.
   Отметили выполнение — начался новый цикл, и при новом «скоро»
   напоминание придёт снова.
2. Обязательство «просрочено» — уведомление сразу при переходе,
   дальше повтор не чаще, чем задано у обязательства
   (по умолчанию раз в 7 дней).
3. Счётчику пора вводить показания (нет дольше настроенного
   срока, по умолчанию 90 дней) — уведомление, повтор не чаще
   раза в 7 дней. Счётчик без обязательств не напоминает —
   незачем.
4. Если срок посчитан по оценке счётчика — текст формулируется
   как просьба сверить: «по расчёту подходит срок — проверьте
   пробег», а не «пора менять».

**Кому** (семья заложена):

5. Напоминание получает исполнитель обязательства, а если он
   не назначен — владелец.
6. Про показания счётчика — получатели всех обязательств этого
   счётчика, каждому одно, без дублей.

**Тихие часы** (правило 9 анализа):

7. У каждого получателя свои тихие часы (по умолчанию
   22:00–09:00). Уведомление, созданное в тихие часы, ждёт
   и уходит первым прогоном после их конца — «накопившееся
   уходит утром».
8. Пока уведомление ждёт отправки, дубль не создаётся — прогоны
   раз в 4 часа журнал не засоряют.

**Честность журнала:**

9. Уведомление «отправлено» — только когда канал реально принял
   его. Пока каналов нет — статус «ожидает». (Хвост для задачи
   бота: при подключении Telegram не вываливать пачку
   залежавшихся — решится там.)

## Как проверим

- дано: «Масло ДВС» в состоянии «скоро» по оценке пробега →
  когда: планировщик делает прогон → тогда: в журнале
  уведомление владельцу с текстом «по расчёту подходит срок —
  проверьте пробег», статус «ожидает»
- дано: то же уведомление уже в журнале → когда: следующий
  прогон через 4 часа → тогда: дубля нет
- дано: просроченное, о нём напоминали 3 дня назад → когда:
  прогон → тогда: нового нет; напоминали 8 дней назад — новое
  создаётся
- дано: прогон в 23:00 находит новое «скоро», тихие часы
  22:00–09:00 → когда: создаётся уведомление → тогда: оно
  помечено «не раньше 09:00» и уходит первым прогоном после
- дано: показаниям пробега больше 90 дней → когда: прогон →
  тогда: уведомление «введите показания» получателям
  обязательств счётчика
- дано: выполнение отмечено, новый цикл дошёл до «скоро» →
  когда: прогон → тогда: напоминание приходит снова
- дано: админка → когда: открывается журнал уведомлений →
  тогда: видны получатель, текст, статус, времена
- тесты pytest зелёные до коммита
