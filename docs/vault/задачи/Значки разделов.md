# Значки разделов

## Зачем

Разделы сейчас различаются только словом и оттенком карточки.
Слово читается, а не узнаётся: на телефоне в ленте из семи пилюль
глаз каждый раз перечитывает названия. Значок узнаётся быстрее слова
и держится в памяти вместе с цветом раздела.

## Что именно делаем

1. У раздела в справочнике появляется **значок** — выбирается плиткой
   из готового набора (16 картинок: машина, дом, участок, семья, деньги,
   здоровье, учреждение, вещи, животные, работа, учёба, ремонт, поездки,
   быт, техника, спорт). Значок можно не выбирать — тогда раздел
   выглядит как сегодня.
2. Значок показывается **в кружке того же оттенка, что и карточки дел
   этого раздела** (вариант «В» мокапа от 2026-08-23): цвет и картинка
   держатся вместе.
3. Где появляется: лента разделов на телефоне, меню слева на компьютере,
   шапка страницы раздела, справочник разделов, факт «к чему относится»
   в карточке дела.
4. В подписи карточки дела в списке значок **заменяет слово раздела**:
   «Транспорт · Hyundai Tucson · каждые 180 дней» становится короче
   на слово и перестаёт переноситься на вторую строку.
5. Семи заведённым разделам значки проставляются сразу при обновлении,
   по названию. Новому разделу значок подставляется по названию тоже
   («машина» в названии → машинка), сменить можно всегда.

**Не делаем:** значков в сообщениях Telegram (там текст и так короткий)
и в выпадающем списке «раздел» на форме дела — обычный список
картинок не показывает, а переделывать его ради этого не стоит.

## Затрагивает

- `core/models.py` — поле «значок» (`icon`) у раздела + миграция схемы
- миграция данных — проставить значки семи существующим разделам
- `core/значки.py` — новый файл: набор картинок и подбор по названию
- `core/forms.py`, `core/views.py` — выбор значка плитками, автоподбор
  по названию, передача значка и номера оттенка на экраны
- `core/admin.py` — значок в списке разделов админки
- `core/templates/core/_значки.html` — новый файл: сам набор картинок
- `base.html` — стили кружка, восемь пар «фон + цвет значка»
- `_меню.html`, `_дело.html`, `section.html`, `catalog.html`,
  `obligation.html` — где значок показывается
- `tests/test_main_screen.py`, `tests/test_zavedenie.py` — проверки

Расчёты (`core/status.py`), правила записи (`core/actions.py`)
и бот не трогаем.

## Бизнес-правила

1. **Значок — необязательный.** Раздел без значка показывается как
   сегодня: пустого места и «дырки» в строке не остаётся.
2. **Набор закрытый** — 16 картинок, свои файлы пользователь
   не загружает. Картинки нарисованы для проекта: одна толщина линии,
   один размер, красятся цветом; ничего не тянется из интернета
   (как и весь остальной вид системы).
3. **Цвет кружка — оттенок раздела**, тот же, что у карточек его дел.
   Оттенок по-прежнему следует из места раздела в справочнике, руками
   не заводится.
4. **В списке дел кружок мелкий** (с прописную букву) и приглушённый:
   рамка «просрочено / сегодня / скоро» остаётся главной на экране,
   значок не должен с ней спорить.
5. **В подписи карточки значок стоит вместо слова раздела.** На странице
   раздела его нет — там раздел уже в шапке.
6. **Автоподбор по названию** срабатывает только когда значок не выбран
   руками, и только при сохранении раздела. Не угадалось — остаётся пусто.
7. **Слово раздела никуда не исчезает** из ленты, меню, шапки
   и справочника: значок стоит рядом, а не вместо.
8. **Значок не влияет ни на расчёты, ни на напоминания** — это только вид.

## Как проверим

- дано: раздел «Транспорт» со значком «машина» → когда: открыта главная
  на телефоне → тогда: в ленте пилюля «(машинка в голубом кружке)
  Транспорт 1 · 3», кружок того же оттенка, что карточка дела
- дано: дело «Замена ДВС» в списке → когда: смотрим подпись → тогда:
  вместо слова «Транспорт» мелкий кружок со значком, дальше
  «Hyundai Tucson · каждые 180 дней» в одну строку
- дано: страница раздела «Дом» → когда: открыта → тогда: в шапке крупный
  кружок со значком и название словом
- дано: справочники → когда: заводим раздел «Гараж» и значок не выбираем
  → тогда: сохраняется со значком «машина» (гараж — про машину),
  а раздел «Тётя Валя» — без значка, и это не мешает ему работать
- дано: разовое дело уже выполнено → когда: открыта его карточка →
  тогда: значок раздела на месте, хотя в списках дела больше нет
- дано: раздел без значка → когда: открыта главная → тогда: пилюля
  выглядит как сегодня, пустого кружка нет
- дано: просроченное дело раздела с ярким оттенком → когда: открыт список
  → тогда: красная рамка видна первой, кружок её не перебивает
- тесты pytest зелёные до коммита
