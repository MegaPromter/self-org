# Хлебные крошки и кликабельный заголовок

## Зачем

Со страниц без бокового меню (справочники, предмет, счётчик,
человек, карточка дела, формы) нет пути назад, кроме кнопки
браузера: заголовок «Self-org» не ссылка, крошек нет.

## Что именно делаем

1. «Self-org» в шапке становится ссылкой на главную на всех
   страницах.
2. Над заголовком каждой страницы, кроме главной и входа, строка
   крошек: путь от главной, последний элемент — текущая страница,
   без ссылки.
3. Пути:
   - Справочники: Главная › Справочники
   - Предмет, человек: Главная › Справочники › Hyundai Tucson
   - Счётчик: Главная › Справочники › Hyundai Tucson › пробег
   - Раздел: Главная › Транспорт
   - Все дела: Главная › Все дела
   - Карточка дела: Главная › Транспорт › Замена ДВС (дело без
     раздела — через «Все дела»)
   - Новое дело: Главная › Новое дело; правка дела: Главная ›
     Транспорт › Замена ДВС › Правка
   - Формы справочников (предмет, счётчик, человек, раздел):
     Главная › Справочники › Правка: пробег
4. Ссылка «← назад» в формах остаётся: она возвращает точно туда,
   откуда пришли, крошки — по структуре.

Мокап показан и одобрен 2026-09-06 (крошки серой строкой над
заголовком, последний элемент без ссылки).

## Затрагивает

- `core/templates/core/base.html` — шапка, стиль крошек, место
  под них
- шаблоны страниц: catalog, item, meter, person, obligation,
  section, all, form, form_simple
- `tests/test_main_screen.py`, `tests/test_spravochniki.py` —
  проверки крошек и шапки

Представления не меняются.

## Бизнес-правила

1. **Крошки строятся по структуре данных**, не по истории
   переходов: у дела — его раздел, у счётчика — его предмет.
2. **Последний элемент не ссылка.** На главной и странице входа
   крошек нет.
3. **На телефоне** строка переносится, горизонтальной прокрутки
   нет.

## Как проверим

- дано: страница справочников → когда: нажато «Self-org»
  в шапке → тогда: главная
- дано: страница счётчика «пробег» → когда: открыта → тогда: над
  заголовком «Главная › Справочники › Hyundai Tucson › пробег»,
  первые три — ссылки, ведут куда названы
- дано: правка «Замены ДВС» → когда: открыта → тогда: «Главная ›
  Транспорт › Замена ДВС › Правка», «← назад» на месте
- дано: главная → когда: открыта → тогда: крошек нет
- тесты pytest зелёные до коммита
