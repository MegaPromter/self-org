# Счётчик в форме дела: одно показание

## Зачем

В форме дела два числа про счётчик — «текущее показание» и «показание
счётчика тогда» — и пользователь не понимает, зачем оба. Текущее
показание — число про машину, а не про дело, и для него уже есть
блок «Счётчики» на главной. Про дело важно одно: пробег в день, когда
его делали, — от него идёт отсчёт «каждые N км».

## Что именно делаем

1. Поле «текущее показание» из формы дела убирается (добавлено утром
   в [[Счётчик в форме дела]], отменяется). Текущий пробег вводится
   на главной в блоке «Счётчики».
2. Остаётся одно поле рядом с «когда делали последний раз»:
   для автомобиля из раздела «Транспорт» — «пробег в день
   выполнения», для прочих счётчиков (водомер, моточасы) —
   «показание в день выполнения». Подсказка: «От него считается
   «каждые N км»».
3. Подпись меняется при выборе счётчика в форме; без JavaScript
   и у нового дела — общая «показание в день выполнения».

Решение пользователя 2026-09-06: слово «пробег» — именно для
автомобиля из раздела «Транспорт».

## Затрагивает

- `core/forms.py` — поле и подпись, список счётчиков с признаком
  «транспорт», удаление «текущего показания»
- `core/views.py` — предупреждение о показании больше не нужно
- `core/templates/core/form.html` — поле, подпись, скрипт
- `tests/test_zavedenie.py` — тесты

## Бизнес-правила

1. **«Транспорт» определяется по разделу предмета** счётчика
   (свой или унаследованный). Раздел переименовали — подпись
   становится общей «показание в день выполнения», данные
   не страдают.
2. **Показание в день выполнения** записывается вместе с отметкой
   выполнения и как показание счётчика на ту дату — как сейчас
   у «показания тогда»; при правке подставляется из последней
   отметки и без изменений не дублируется (`f7e24c7`).
3. **Дело «по счётчику» без показания в день выполнения** —
   «нет данных», как сейчас.

## Как проверим

- дано: правка «Замены ДВС» (Tucson, раздел «Транспорт») → когда:
  открыта → тогда: поля «текущее показание» нет, рядом с датой —
  «пробег в день выполнения»
- дано: дело по водомеру квартиры → когда: открыта правка → тогда:
  подпись «показание в день выполнения»
- дано: правка «Замены ДВС», введён пробег 118 000 → когда:
  сохранено → тогда: у отметки 31.08 показание 118 000, в карточке
  «через … км»
- тесты pytest зелёные до коммита
