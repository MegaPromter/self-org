# Мелкие правки (журнал)

Малая форма из регламента (принцип 3): правка в 1–2 файлах
без изменения бизнес-правил, без новых зависимостей и миграций.
Отдельная заметка не заводится — строка в таблице ниже.

Согласование всё равно обязательно: ассистент говорит
«это малая форма, делаю так-то», пользователь подтверждает.

Косметика (форматирование, опечатки, фиксы линтера, откат
ошибок ассистента) сюда **не** попадает — она не документируется
вовсе, в коммите ставится метка-исключение.
