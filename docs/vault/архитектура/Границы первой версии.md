# Границы первой версии

## Зачем

Договорённость «проектируем на весь объём, запускаем частями»
требует зафиксировать, где проходит граница первого рабочего
выпуска. Без неё каждая задача рискует расползаться («а давайте
заодно…»), а «готово» не имеет ясного смысла.

## Исходные данные

Решения пользователя от 2026-08-18:

- **Финиш первой версии — работает на домашнем компьютере.**
  Переезд на сервер — отдельная задача после обкатки. Следствие,
  названное честно: до переезда напоминания приходят только пока
  компьютер включён; платить за сервер до обкатки не начинаем.
- **Канал уведомлений — только Telegram.** Почта — после выпуска;
  архитектура каналов закладывается сразу, добавление почты
  потом — недорого.
- **Кнопки в уведомлении — в первом выпуске**: отмечать
  выполнение, не открывая сайт, — ядро удобства.
- **Шаблоны предметов — позже**: для одной машины десять записей
  вводятся руками один раз.

## Что входит в первую версию

1. **Модель данных полная** — обязательство, предмет, счётчик,
   человек, выполнение; владелец и исполнитель; личное и общее.
   На весь объём, включая семью, — переделка потом дороже.
2. **Все три вида правила срока** — по времени, по счётчику,
   оба сразу (срабатывает наступивший раньше).
3. **Расчёт по счётчику** — средний темп по двум последним
   вводам, между вводами расчётная оценка с пометкой,
   необязательный ожидаемый годовой расход.
4. **Состояния и уведомления** — в норме / скоро (70 % интервала,
   порог настраиваемый) / просрочено; тихие часы; повтор
   о просроченном не чаще раза в неделю; напоминание ввести
   показания, если их нет дольше квартала. Всё — правила 1–11
   из [[Анализ требований и разбор аналогов]].
5. **Telegram-бот с кнопками** — «сделано», «отложить», «ввести
   показание» прямо из уведомления (правило 12).
6. **Интерфейс**: главный экран (список по близости срока,
   состояние, сколько осталось, доля интервала, оценки
   помечены), разделы, отметка выполнения и ввод показаний —
   плюс **свои экраны заведения и правки данных**. Последнее
   переехало сюда из «отложено» 2026-08-23: пользователь
   вводит реальные данные, и делать это в админке неудобно.
   Админка остаётся запасным входом.
7. **Проверяется на технике** — машина, дом, хозяйство.
   Обязательства «только по времени» (дни рождения, финансы)
   ложатся в ту же модель и работают без доработок, но отдельной
   доводки под них (поля подарков и т. п.) в первой версии нет.

## Что не входит — и когда появится

| Отложено | Почему не страшно |
|---|---|
| Сервер, доступ извне | отдельная задача после обкатки дома; только тогда начинается оплата 500–800 ₽/мес |
| Почта как канал | Telegram покрывает; канал добавится в заложенную архитектуру |
| Шаблоны предметов, самообучение интервалов, отпуск, недельная сводка | удобства, не ядро; ценны при массовом заведении |
| Семейный доступ в интерфейсе (приглашения, права) | модель готова, экраны — когда появится второй пользователь |

| События Google Календаря внутри системы | открытый вопрос остаётся открытым, календарь работает как работал |

## Очередь задач первой версии

1. Модель данных (+ админка на ней)
2. Расчёт сроков и состояний
3. Планировщик: регулярная проверка сроков, тихие часы
4. Telegram-бот: уведомления и кнопки
5. Главный экран
6. Обкатка на реальных данных пользователя

Каждая — отдельная задача по регламенту, со своей заметкой.

## Затрагивает

Только эту заметку и память проекта. Кода в задаче нет.

## Как проверим

- дано: раздел «Что входит» → когда: пользователь читает →
  тогда: про каждый пункт может сказать «да, это нужно в первую
  очередь» — или возразить

- дано: раздел «Что не входит» → когда: пользователь читает →
  тогда: по каждой строке видит, почему без неё можно жить
  и когда она появится

- дано: очередь задач → когда: закрывается очередная задача →
  тогда: следующая берётся из очереди без обсуждения «что дальше»

- дано: выпуск по этим границам готов → когда: пользователь дома
  заводит машину и её работы → тогда: получает в Telegram
  напоминание с фактурой и кнопками и отмечает выполнение,
  не открывая сайт
