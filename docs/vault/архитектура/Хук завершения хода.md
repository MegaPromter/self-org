# Хук завершения хода

## Зачем

Дважды повторялся один сбой: ассистент показывал команду штампа,
пользователь нажимал Run — и сессия молчала, потому что ассистент
забывал запустить фонового наблюдателя за табло. Приходилось
писать в чат вручную. Забывчивость не лечится текстом инструкции —
только скриптом (принцип 10 регламента плагина).

## Решение

Седьмой хук слоя принуждения — `check_turn_end.py` на событие
Stop (ассистент закончил ход). Установлен из плагина
reglament-plugin v1.2.1 (репозиторий
https://github.com/MegaPromter/reglament-plugin, заметка
«Правка-хука-по-итогам-проверки» там же).

Что делает: в фазе «заметка» (полная форма, штампа нет) не даёт
ассистенту молча закончить ход. Два случая:

1. Нет ни вопроса пользователю, ни призыва к штампу — разворот
   с инструкцией завершить ход явным действием.
2. Призыв прозвучал, но фоновый наблюдатель за табло не запущен
   — разворот с указанием запустить наблюдателя (ищется по
   background_tasks; поля нет — проверка молча пропускается).

Ход-вопрос пропускается: согласование ещё идёт, штамп рано.
Защита от цикла — встроенный stop_hook_active (после 8
блокировок Claude Code перебивает хук сам).

## Файлы

- `.claude/hooks/check_turn_end.py` — сам хук;
- `.claude/settings.json` — секция Stop (без matcher: событие
  его не поддерживает).

## Ограничение

Проверено прогоном 12 сценариев на копии `.claude` этого
проекта; в живой сессии Stop-событие ещё не срабатывало —
первая настоящая проверка случится в ближайшей задаче полной
формы.
