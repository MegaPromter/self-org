# Документация проекта Self-org

Вход для нового человека — или для новой сессии ассистента.

## Что за проект

Система персональной организации. Хранит регулярные и разовые
обязательства (хозяйство, машина, дом, родня, финансы,
общественное), знает даты и интервалы, **заранее напоминает**
в Telegram.

Рядом с задачей живёт фактура: где лежит, номер детали, цена,
дата заказа. Пример из исходной идеи: не просто «поменять
резину», а «поменять резину — хранится там-то, заказана тогда-то,
номер такой-то».

Горизонт развития: доступ извне с любого устройства,
многопользовательский режим для семьи.

## С чего начать чтение

1. **`_meta/Регламент.md`** — правила разработки. Источник
   истины: при расхождении с уставом, навыком или памятью
   ассистента прав регламент.
2. **`CLAUDE.md`** в корне проекта — краткий устав, его читает
   ассистент в начале каждой сессии.
3. **`задачи/`** — что делалось и делается, с историей коммитов.
4. **`архитектура/`** — принятые решения и обоснования.

## Как устроена папка

```
docs/vault/
├── README.md        этот файл
├── _meta/           регламент, шаблоны
├── модули/          описания частей системы
├── задачи/          заметка на каждую задачу + журнал мелких правок
└── архитектура/     принятые решения (ADR)
```

Папки создаются по мере появления первых заметок — пустых нет.

## Как ведётся работа

Задача → заметка в чат → согласование с пользователем → код →
тесты → коммит со ссылкой на заметку → хэш коммита в заметку.

Каждая задача начинается командой `/reglament`.

## Состояние проекта

Проект в начальной стадии: согласованы правила работы,
проведён анализ требований и разбор аналогов, выбран стек
(`архитектура/` — обе заметки). Кода нет.

Ближайшие задачи: скелет проекта, границы первой версии.
